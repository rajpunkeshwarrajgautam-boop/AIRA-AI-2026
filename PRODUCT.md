# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primary users are software engineers, researchers, technical founders, and knowledge professionals who require high-reasoning intelligence, deep synthesis, project document context, and autonomous multi-step agent delegation in a focused, high-craft workspace.

## Product Purpose

AIRA AI provides a unified, production-grade intelligence workspace ("One workspace. Every intelligence.") that bridges everyday conversational reasoning and autonomous agent execution. It replaces cluttered, fragmented AI tools with a calm, tactile editorial environment engineered for deep focus, deterministic verification, and reliable task completion.

## Positioning

Unlike generic AI interfaces built on cold blue-slate corporate templates with simulated metrics, AIRA AI is built around a warm editorial aesthetic (Copernicus serif headlines and warm terracotta accents) paired with strict server-authoritative entitlements, transparent credit settlement, zero fake mocks, and verified database isolation.

## Operating Context

- **Conversational Reasoning & Research:** Fast and deep model exploration, extended thinking, and live code execution in a focused chat stream.
- **Artifact Output Studio:** Split-screen reactive workspace for interactive prototypes, SVGs, documents, and code files with sandboxed iframe execution.
- **Autonomous Agent Mode:** Multi-step mission delegation, tool invocation (browser, terminal, search), and builder workspace execution with verifiable deliverables.
- **Project Knowledge Management:** Project slots with linked reference documents, custom instructions, and persistent context.
- **Agent Persistent Memory Vault:** 4-tier memory engine (Semantic, Episodic, Procedural, Working) persisting user preferences across sessions.
- **Keyboard & Touch Ergonomics:** Full keyboard navigation (`Ctrl+K` Command Palette, `Ctrl+N` new chat, `Escape` dialog dismiss, arrow-key navigation) and touch targets optimized for mobile.

## Capabilities and Constraints

- **Workspace Modes:** Dynamic two-segment switch between conversational `Chat` and autonomous `Agent`.
- **Model Routing:** Fast, Pro, and deep reasoning models with adaptive provider failover and extended thinking toggle.
- **Entitlement Tiers:** Strictly governed Guest (5 chats/day, 0 credits, 0 projects), Free, Plus, and Pro tiers with live quota verification.
- **Security & Privacy:** Server-enforced RBAC, Neon PostgreSQL tenant isolation, zero client-side credential exposure, and privacy scrubbing in memory.
- **Performance:** Sub-100ms UI interactions, GPU-accelerated motion tokens, and zero layout overflow.

## Product Principles

1. **Substance Over Simulation:** Every counter, quota, and state is verified against authoritative backend systems; never fabricate mock success.
2. **Warm Humanist Craft:** Editorial warmth, bespoke serif typography, and tactile physical presence over disposable AI aesthetics.
3. **Accessibility as a Floor:** Full WCAG AA conformance, minimum 40px touch targets, complete ARIA semantics, and graceful keyboard operation across every surface.
4. **Calm Precision:** Maintain zero layout overflow, predictable spacing rhythm, and purposeful motion that honors user motion preferences.
5. **Durable Context:** Provide continuous, reliable project and session continuity through persistent memory and structured knowledge.

## Accessibility & Inclusion

- Adherence to WCAG 2.1 AA standards across light and dark modes.
- Interactive element hit targets meet or exceed 40×40px on mobile and 28×28px on desktop.
- Contrast ratios of at least 4.5:1 for standard text and 3:1 for large display headlines and controls.
- Comprehensive `prefers-reduced-motion` guards disabling spring physics for sensitive users.
- Accessible modal dialogs with `aria-modal="true"`, heading associations, and keyboard focus containment on `Escape`.
