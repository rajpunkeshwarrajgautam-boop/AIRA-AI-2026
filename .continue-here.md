## 2. Root Cause Discovered for Vercel Preview Deployments

- On Vercel Preview deployments for PR branches, `DATABASE_URL` is NOT automatically configured (in Vercel project settings, `DATABASE_URL` was scoped only to `Production` and the dedicated `staging` branch).
- When `DATABASE_URL` is undefined, `packages/db/src/index.ts` falls back to `postgres://aira:aira@localhost:5432/aira_db`. In a Vercel serverless function, connecting to `localhost:5432` throws `ECONNREFUSED`.
- `apps/api/src/index.ts` was unconditionally initializing `PostgresRunRepository` and attempting DB seeding (`seedDefaultAgent`, `seedDefaultAutomation`) on every cold start.
- **Solution for Tomorrow Morning**:
  - In `apps/api/src/index.ts`:
    ```typescript
    const isDbConfigured = Boolean(process.env.DATABASE_URL?.trim());
    const runRepo = isDbConfigured ? new PostgresRunRepository() : new InMemoryRunRepository();
    if (isDbConfigured) {
      seedDefaultAgent().catch(console.error);
      seedDefaultAutomation().catch(console.error);
    }
    ```
  - In `apps/api/src/auth/bff-session.ts`:
    - In `BffSessionStore`, provide in-memory map storage fallback if `!process.env.DATABASE_URL?.trim()`.
  - When `isDbConfigured` is `true` (in production and staging), it uses PostgreSQL exactly as normal.
  - When `isDbConfigured` is `false` (on Vercel Preview deployments), it uses `InMemoryRunRepository`, enabling real live NVIDIA NIM model streaming without requiring an external DB connection.
