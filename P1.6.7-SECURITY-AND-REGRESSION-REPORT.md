## 1. Authentication & Tenant Isolation Audit

### Cryptographic Identity Gateway:
AIRA AI 2026 utilizes Neon Auth (Better Auth) with EdDSA cryptographic signatures.
- **JWKS Endpoint**: `https://ep-empty-field-b36mqqq6.neonauth.c-4.ap-southeast-1.aws.neon.tech/neondb/auth/.well-known/jwks.json`
- **Validation**: Every authenticated request is cryptographically validated via `verifyNeonAuthToken` before reaching application routing logic.
- **Principal Derivation**: `ExecutionPrincipal` is constructed strictly server-side (`neon_user_<uuid>`). Client-provided user IDs, headers, or parameters are ignored and rejected.
