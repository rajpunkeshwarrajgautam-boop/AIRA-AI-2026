## 4. Tertiary Fallback Restriction Deep-Dive

### Why `allam-2-7b` is Strictly Prohibited on Groq Quota Limits:
- Both `openai/gpt-oss-120b` and `allam-2-7b` execute on the **same upstream Groq organization account**.
- If Groq returns HTTP 429 with `TPD` (Tokens Per Day) or `TPM` (Tokens Per Minute) limit reached, calling `allam-2-7b` immediately fails with the identical quota error, amplifying latency and consuming rate limit tokens needlessly.
- `ResilientModelAdapter` inspects the error message and status code:
  ```typescript
  const isAccountLevelLimit = 
    err.status === 429 ||
    err.message.includes('TPD') ||
    err.message.includes('TPM') ||
    err.message.includes('quota') ||
    err.message.includes('rate_limit');
  ```
  If `isAccountLevelLimit` is `true`, `tertiaryAdapter` invocation is completely skipped, and the request fails closed immediately.

### Why NVIDIA Nemotron is Strictly Prohibited from Fast Path:
- `nvidia/nemotron-3-super-120b-a12b` is a high-latency reasoning model with median TTFT exceeding 6,000ms.
- Promoting Nemotron as a fallback for `aira-fast` would degrade TTFT by >500% and violate the P1.6 latency budget.
- `LatencyAwareRoutingPolicy.selectFastExecutionPlan` strictly denies Nemotron from the Fast candidate pool.
