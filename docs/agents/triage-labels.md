# Triage Labels Vocabulary — AIRA AI 2026

The canonical triage roles mapped for AIRA AI 2026:
- `needs-triage`: Newly submitted issue or regression needing specialist classification
- `needs-info`: Awaiting external provider response, merchant KYC update, or user clarification
- `ready-for-agent`: High-clarity implementation task ready for autonomous agent execution
- `ready-for-human`: Action requiring explicit maintainer authorization (e.g. GO LIVE, live merchant keys)
- `wontfix`: Out-of-scope or rejected request
